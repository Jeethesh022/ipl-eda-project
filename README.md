Project: IPL EDA (2008–2024)

Insights:
- Avg innings score trend
- Sixes trend
- Run rate trend
- Bowling economy trend

Datasets:
-The dataset used in this project is IPL 2008–2024 ball-by-ball data.
-Due to large file size, the dataset is not included in this repository.
-It can be downloaded from Kaggle or IPL dataset sources and used in Google Colab.

Tools: Python, Pandas, Matplotlib, Seaborn
